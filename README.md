# vu-sport

Minimal Expo-ready React Native scaffold with **Splash**, **Login**, and **Signup** screens,
externalized styles and global components, and React Navigation already wired.

## Run
```bash
yarn install
yarn start
```

## Structure
- `src/navigation/RootNavigator.js` – Stack with Splash → Login → Signup
- `src/screens/*` – Screen components
- `src/components/*` – GlobalButton, CustomTextInput
- `src/styles/*` – Colors and shared styles
- `src/constants/*` – App-wide constants
